## 2. 负向 5 类注入结论 <a id="negative"></a>

| # | 注入方式 | 对应用例 | 结论 |
| --- | --- | --- | --- |
| 1 | 代码已变但记录被篡改 / 键保持不变（假命中） | `test_tampered_record_is_not_hit`、`test_code_change_invalidates_even_without_add` | 通过：键不符即不命中；未 `git add` 的改动同样使输入指纹变化 |
| 2 | 记录损坏（非法 JSON / 结构版本不符 / 顶层形态错误）、记录不可写 | `test_corrupt_record_falls_back_to_run`、`test_record_schema_mismatch_and_shapes`、`test_write_failure_is_non_fatal` | 通过：损坏即全部真跑；写失败只打印原因、不改变本次判定 |
| 3 | 未登记步骤 / 非法 `scope` / 非法 `checks_runner` | `tests/test_config.py`（配置解析失败即退出） | 通过：`ConfigError` fail-closed，零步骤执行 |
| 4 | 真实缺陷注入（类型错误 / 覆盖率缺口 / 死链） | 本次实施自身经历：pyright strict 0 错误、ruff 2 处（行宽 + 无效 noqa）、文档 7 处断链 | 通过：三类缺陷均被拦下并修复后复检通过 |
| 5 | 跨仓配置差异（配置变化不得互相命中） | `test_env_fingerprint_tracks_config`、`test_record_does_not_change_fingerprint` | 通过：环境指纹随 `engkit.toml` 变化；记录自身写入不改变指纹 |
