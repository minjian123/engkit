## 1. 这是什么 <a id="what"></a>

`engkit` 把原本散落在单个仓库里的工程化护栏抽成**一个可安装包 + 一份仓配置**：

- 文档**链接与锚点**校验、文档**口径护栏**（进度类字段只允许落在阶段计划）；
- 本地**预检**（档位 / 预算 / 步骤调度）与**重命令包装**（缓存回放、未包装拦截）；
- 变更影响分析**选测**与**覆盖率门禁**（选测器与护栏只有一份实现）；
- **Kiwi TCMS 用例登记**与回读。

各仓只写仓根一份 `engkit.toml`，包内不含任何仓名与目录字面（机器断言）。

## 3. 五分钟上手 <a id="quick"></a>

```bash
uv sync                                  # 本仓开发环境
engkit links                             # 文档链接与锚点
engkit docs-scope                        # 文档口径
engkit push                              # 推送入口：预检通过才推送（档位按待推提交自动选）
engkit push --check                      # 只跑预检、不推送（唯一出口）
```

> 各仓接入把上面命令换成自己仓根执行即可；命令名与参数完全一致。

## 4. 门禁口径 <a id="gate"></a>

- 覆盖率门槛见《AI开发规范》「覆盖率要求」节（本包不复述数字）；
- 本仓门禁为**双轨**：基础门禁直跑（`pytest` / `ruff` / `pyright`）+ 自举烟雾（`engkit preflight --fast`），见仓根 `.gitlab-ci.yml`。
